# 🌍 İklim Değişikliği Farkındalık Platformu

İklim değişikliği hakkında bilgi edinmeyi, güncel gelişmeleri takip etmeyi ve çevre dostu görevleri tamamlayarak puan kazanmayı sağlayan bir web sitesidir.

## 📌 Proje Hakkında

Bu proje, kullanıcıların iklim değişikliği hakkında bilgi edinmesini ve çevre konusunda daha bilinçli davranmasını amaçlamaktadır.

Web sitesinde bilgi içerikleri, iklim haberleri, günlük görevler ve kullanıcı profili bulunmaktadır.

## 🏠 Ana Sayfa

Ana sayfada iklim değişikliği ile ilgili çeşitli sorular ve cevapları bulunmaktadır.

Örnek konular:

* İklim değişikliği nedir?
* İklim değişikliği neden olur?
* İklim değişikliğinin etkileri nelerdir?
* İklim değişikliğini nasıl yavaşlatabiliriz?
* Bireysel olarak neler yapabiliriz?

## 📰 Haberler

Haberler bölümünde iklim değişikliği ve çevre ile ilgili güncel haberler yer almaktadır.

Haberlerde;

* 🌍 İklim değişikliği
* 🌡️ Küresel ısınma
* ♻️ Geri dönüşüm
* ☀️ Yenilenebilir enerji
* 🌱 Çevre ve doğa

gibi konular ele alınmaktadır.

## 🌱 Günlük Görevler

Kullanıcıların her gün tamamlayabileceği farklı çevre dostu görevler bulunmaktadır.

Örneğin:

* ♻️ Geri dönüşüm yapmak
* 💧 Su tasarrufu yapmak
* 💡 Gereksiz ışıkları kapatmak
* 🚶 Kısa mesafelerde yürümek
* 🌳 Bitki veya ağaçlarla ilgilenmek

Bir görev tamamlandığında kullanıcı puan kazanır.

## 👤 Kullanıcı Profili

Profil bölümünde kullanıcının yaptığı görevler ve kazandığı puanlar gösterilir.

Profilde:

* Tamamlanan görevler
* Kazanılan toplam puan
* 🌍 Sen ve İklim Puanı
* Görev geçmişi

gibi bilgiler bulunmaktadır.

## 🌍 Sen ve İklim Puanı

Kullanıcıların tamamladıkları çevre dostu görevlerden kazandıkları puanları gösteren sistemdir.

Kullanıcı daha fazla görev tamamladıkça puanı yükselir.

## 🎯 Projenin Amacı

Projenin amacı, iklim değişikliği hakkında farkındalık oluşturmak ve kullanıcıları çevreye daha duyarlı davranışlara teşvik etmektir.

Bilgilendirici içerikler, haberler ve görev sistemi bir araya getirilerek etkileşimli bir web sitesi oluşturulmuştur.

## 💻 Kullanılan Diller

Projede kullanılan temel programlama dilleri:

* 🐍 **Python**
* 🌐 **HTML**
* 🎨 **CSS**
* ⚡ **JavaScript**

## 📚 Kullanılan Kütüphaneler

Python tarafında kullanılan kütüphaneler:

* **Flask** – Web uygulamasını oluşturmak ve sayfaları yönetmek için
* **Jinja2** – HTML sayfalarında dinamik içerik göstermek için

> Eğer projede başka Python kütüphaneleri kullanılıyorsa bu listeye eklenebilir.

## 🚀 Projeyi Çalıştırma

Projeyi çalıştırmak için öncelikle Python'un bilgisayarınızda kurulu olması gerekir.

Gerekli kütüphaneleri yüklemek için:

```bash
pip install flask
```

Daha sonra Python dosyasını çalıştırın:

```bash
python app.py
```

Ardından terminalde belirtilen yerel adresi tarayıcıda açarak web sitesine ulaşabilirsiniz.
